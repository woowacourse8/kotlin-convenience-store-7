# 🏪 편의점

구매자의 할인 혜택과 재고 상황을 고려하여, 최종 결제 금액을 계산하고 안내하는 결제 시스템입니다.

## 🎯 기능 목록

### 1. 초기 설정 및 데이터 로드
- [x] 상품 목록 로드: `products.md` 파일을 읽어 상품명, 가격, 재고, 프로모션 정보를 저장한다.
  - [X] 동일 상품의 프로모션 재고와 일반 재고를 구분하여 관리한다.
- [x] 프로모션 목록 로드: `promotions.md` 파일을 읽어 행사명, 조건(N+1), 기간을 저장한다.

### 2. 상품 구매 (핵심 로직)
- [x] 재고 확인 및 차감
  - [x] 구매 수량만큼 재고를 차감한다. (프로모션 재고 -> 일반 재고 순서)
  - [x] 재고보다 많은 수량을 입력하면 예외(`IllegalArgumentException`)를 발생시킨다.
- [x] 프로모션 할인 적용 (N+1)
  - [x] 오늘 날짜가 프로모션 기간 내인지 확인한다. (`DateTimes.now()`)
  - [x] 프로모션 재고 내에서 N+1 혜택을 계산하여 증정 상품을 도출한다.
- [x] 멤버십 할인 적용
  - [x] 프로모션 미적용 금액(정가 구매분)의 30%를 할인한다.
  - [x] 멤버십 할인의 최대 한도는 8,000원으로 제한한다.
     
### 3. 입출력 (View)
- [x] 상품 목록 출력: 현재 보유 중인 상품 정보(재고, 프로모션 여부)를 포맷에 맞춰 출력한다.
  - [x] 재고가 0인 경우 "재고 없음"을 출력한다.
- [x] 주문 입력: `[상품명-수량],[상품명-수량]` 형식으로 입력받는다.
- [x] 추가 안내 입력 (Y/N)
  - [x] 프로모션 혜택을 받기 위해 추가로 가져올 수 있는 경우 안내한다.
  - [x] 프로모션 재고가 부족하여 정가로 결제해야 하는 경우 안내한다.
  - [x] 멤버십 할인 적용 여부를 입력받는다.
  - [x] 추가 구매 여부를 입력받는다.
- [x] 영수증 출력: 구매 상품, 증정 상품, 금액 정보(총구매액, 행사할인, 멤버십할인, 최종결제금액)를 정렬하여 출력한다.

### 4. 예외 처리
- [x] 입력 형식 오류: `[상품-수량]` 형식이 아닌 경우, 수량이 숫자가 아닌 경우.
- [x] 재고 부족: 구매하려는 수량이 전체 재고보다 많은 경우.
- [x] 존재하지 않는 상품: 목록에 없는 상품명을 입력한 경우.
- [x] 잘못된 응답: Y/N 입력에 다른 문자를 입력한 경우.
- [x] 공통: 모든 예외 발생 시 `[ERROR]`로 시작하는 메시지를 출력하고, 해당 지점부터 입력을 다시 받는다.
